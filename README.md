## 🚀 Recent Projects

- [Laravel Translate](https://github.com/wazzac/domTranslate): _(Active|v2.5.0)_ ✅ The Laravel Auto-Translation Package enables seamless multilingual support by allowing you to define phrases for automatic translation within your Laravel application. Using a built-in Blade directive, you can easily mark phrases that need translation before displaying them to the user. This package simplifies multi-language management.
- [Sync Model to Crm](https://github.com/wazzac/sync-model-to-crm): _(Active|v1.2.0)_ ✅ Laravel CRM Sync is a powerful package designed to seamlessly integrate and synchronise your Laravel models with multiple CRM systems. This package allows you to define specific model properties that will automatically synchronise with configured CRMs such as HubSpot and Pipedrive, across different environments (e.g., Sandbox, Production).
